# Bundled Latin fonts

These WOFF2 subsets are loaded through `next/font/local` so a Mercury build does not require network access. Chinese headings use the self-hosted Noto Serif SC slices from the `@fontsource/noto-serif-sc` package (imported in `src/app/globals.css`); Chinese body text uses the system CJK stacks documented in `docs/DESIGN.md`.
